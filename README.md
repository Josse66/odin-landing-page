# THE ODIN LANDING PAGE

Proyecto del curso "The Odin Project". Se trata de un proyecto que une HTML y CSS con Flexbox, donde el objetivo fue que, a partir de un diseño dado por el curso, se buscara llegar a uno muy parecido mediante el uso de nuestras habilidades adquiridas, con el fin de practicar y entender de mejor manera el comportamiento de HTML y CSS con Flexbox.

## Demo: 

[Ver la página](https://josse66.github.io/odin-landing-page)

## Habilidades practicadas:
- Estructurar correctamente `divs` a lo largo del HTML.
- Reconocer y etiquetar con nombres descriptivos las clases en un HTML.
- Utilizar estilos CSS que van más allá del fondo o el color de las letras, reconociendo los espacios entre líneas y centrando sin Flex, adaptando `margin` en ambos casos para distribuir la información.
- Anidar Flex, separando la información con contenedores para distribuir el diseño de manera correcta.
- Utilizar `object-fit` para que una imagen ocupe solo el espacio determinado.
- Importar la fuente "Roboto" desde Google.
- Mantener los avances haciendo uso de commits.
